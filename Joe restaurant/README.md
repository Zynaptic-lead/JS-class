# 🍽️ Joe's Restaurant — Live Kitchen & Ordering

A modern, fully-responsive **frontend-only** restaurant website where customers can
**watch chefs cook live** and **order dishes in real time**. No backend required —
everything runs in the browser with vanilla HTML, CSS & JavaScript.

## ✨ Features

- **Live Kitchen player** — auto-playing stream with mute, fullscreen, live viewer
  count, animated progress bar and switchable cooking *stations* (Grill, Pasta,
  Sushi, Dessert).
- **Live chat** — send messages and get auto-replies from "Joe's Kitchen".
- **Interactive menu** — 12 dishes with category filters, ratings, "Live"/"Hot" tags.
- **Shopping cart drawer** — add/remove items, adjust quantities, live subtotal,
  delivery fee & total. Cart persists via `localStorage`.
- **Checkout flow** — animated success modal with an order summary.
- **Meet the Chefs** grid with live badges.
- **Polish** — preloader, sticky glass navbar, scroll-spy nav, mobile hamburger menu,
  toast notifications, newsletter form, smooth animations, fully responsive.

## 🚀 Run it

Just open `index.html` in any modern browser. No build step, no dependencies to install.

> Uses Google Fonts + Font Awesome via CDN, and Unsplash/Coverr media — an internet
> connection gives the best experience.
